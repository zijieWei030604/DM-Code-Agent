# Semantic Workspace SWE-bench Stress Set

This frozen ten-instance set contains one case from each repository represented in the established
50-instance benchmark. It excludes tasks estimated above four hours and deliberately includes
historical outcomes from three categories: Semantic Workspace-only resolved, baseline-only
resolved, and unresolved in both groups.

The set is intended to test whether Semantic Workspace can help difficult trajectories without
regressing cases previously solved by the baseline. Because historical outcomes informed case
selection, results from this set are diagnostic and must not be reported as an unbiased public-set
pass rate.
